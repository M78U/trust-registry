# Safe AIA discovery (experimental)

AIA caIssuers URLs in certificates are untrusted input. Inspect parses one local DER/PEM certificate, lists unique eligible HTTPS URLs and counts unsupported ones. No DNS/HTTP and no OCSP URL retrieval. Fetch requires the operator to select an exact eligible URL from that certificate and a new local output file. Single GET only, no recursion, no fallback, no cookies/auth/client cert, redirects or proxy. No arbitrary URLs, query/fragment, percent escapes, ambiguous path, userinfo, explicit ports, IP literals or local DNS suffixes. Lowercase ASCII multi-label DNS names only, standard HTTPS port 443, simple path. At most 16 AIA URLs, 2048 bytes per eligible URL.

DNS is explicitly resolved for IPv4 only, capped at 16 answers. Reject entire answer set if any prohibited IP (private, loopback, link-local, CGNAT, documentation, benchmark, multicast, reserved etc.). Connect to a checked literal IPv4, never resolve hostname again at dial time; TLS hostname and ordinary platform TLS verification remain enabled. No proxy or redirect, no compression, 30s overall timeout, 32 KiB response headers, 1 MiB body. DNS and HTTPS GET still disclose selected URL/host and client IP; inspect locally first, do not send personal URLs. The IP policy is a conservative static subset, not proof of public routability; routing/NAT, public-addressed internal services, DNS infrastructure and local host trust remain operator responsibilities. Use egress firewall/sandbox for stronger isolation. Do not expose this CLI as a network-facing service or pass untrusted requests automatically.

Fetched bytes must parse as exactly one certificate and satisfy shared direct issuer identity and signature checks (DN, AKI/SKI, CA constraints, critical extensions, cert signing). No PKCS#7, HTTP, LDAP, IPv6, delegated network fetch, recursive chain building or auto import. A self-signed root can match a different child but remains an unreviewed candidate, never an anchor. No time/path/revocation/policy verification follows from a match. The source-file hash covers exact downloaded input, DER fingerprint covers certificate content. Download output uses no-replacement local write (interruption may leave partial file). Audit and import are separate offline operations; source URL is a local assertion, not independently proven retrieval. Do not publish local signer data or unreviewed source/provenance. Explicit import uses existing CA candidate storage.

```sh
trust-registry aia inspect signer.cer
trust-registry aia fetch --url https://ca.example.org/issuer.cer --out issuer.cer signer.cer
trust-registry aia audit --url https://ca.example.org/issuer.cer --candidate issuer.cer signer.cer
trust-registry aia import --url https://ca.example.org/issuer.cer --candidate issuer.cer --registry ./local-registry signer.cer
```
Example URL only; use actual selected URL. The ordinary verify-path and discover operations stay offline. SDK aia.Inspect, Fetch, Audit and registry.MatchIssuer. Synthetic tests cover exact URL selection, wrong issuer, mixed DNS answers, literal IP pinning, malformed/oversized responses. No live network test or Go execution in this round; automatic CI disabled. No production trust.
