DEVELOPER TOOLS / CLI

在本地探索信任

最新源码预览版为 v0.2.0-preview.1；M78U 官方 Homebrew Tap 当前仍提供 Trust Registry 0.1.0 Developer Preview，等待新版包验收。

Homebrew Tap ↗

macOS · Apple Silicon

brew tap m78u/tap
brew install m78u/tap/trust-registry

需要 Homebrew 当前提供 Go 1.26.11；工具链补丁版本变化需重新审核。暂不提供 Bottle 或 Intel 版本。

开始本地研究

trust-registry init --registry ./local-registry
trust-registry validate --registry ./local-registry

仅包含 Registry CLI。未预置可信 CA、生产信任锚或 TUF 管理工具。请勿将研究结果作为正式信任结论。
